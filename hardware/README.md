# 硬件设计文档

## 电路原理图

### 核心元件

| 元件 | 型号 | 数量 | 单价(¥) | 说明 |
|------|------|------|---------|------|
| MCU | ESP32-WROOM-32E | 1 | 12.00 | 主控芯片 |
| 继电器 | SRD-05VDC-SL-C | 1 | 2.50 | 5V 继电器 |
| 继电器驱动 | ULN2003A | 1 | 0.50 | 达林顿阵列 |
| 降压芯片 | AMS1117-3.3V | 1 | 0.50 | 3.3V 稳压 |
| 电解电容 | 470μF/10V | 2 | 0.20 | 滤波 |
| 陶瓷电容 | 100nF | 4 | 0.05 | 去耦 |
| LED | 3mm LED | 2 | 0.05 | 状态指示 |
| 按键 | 6x6 轻触开关 | 1 | 0.10 | 配置/重置 |
| 接线端子 | KF301-2P | 2 | 0.30 | 电源+负载 |
| USB-C | USB-C 母座 | 1 | 0.50 | 供电/调试 |

**总计：约 ¥18 元/台**（不含 PCB）

### 电路连接

```
电源部分：
  5V (USB) ──┬── 470μF ──┬── GND
              │            │
              └── AMS1117 ─┼── 3.3V
              │            │
              └── 100nF ───┘

继电器部分：
  ESP32 GPIO25 ──┬── 1kΩ ──┬── ULN2003 IN1
                  │         │
                  └── LED ──┘
                    
  ULN2003 OUT1 ──── Relay Coil (+)
  GND ───────────── Relay Coil (-)
                    
  Relay COM ─────── 电源火线
  Relay NO ──────── 负载火线

状态指示：
  ESP32 GPIO2 ──── LED ──── 330Ω ──── GND

配置按键：
  ESP32 GPIO0 ──── 按键 ──── GND (内部上拉)
```

## PCB 设计规格

### 尺寸
- 板厚：1.6mm
- 尺寸：50mm x 35mm（两层）
- 孔径：最小 0.3mm
- 走线：最小 6mil

### Gerber 文件生成

使用 KiCad 或 Altium Designer 生成 Gerber 文件，包含：

- F.Cu (顶层铜)
- B.Cu (底层铜)
- F.Paste (顶层锡膏)
- B.Paste (底层锡膏)
- F.SilkS (顶层丝印)
- B.SilkS (底层丝印)
- F.Mask (顶层阻焊)
- B.Mask (底层阻焊)
- Edge.Cuts (板框)

## 外壳设计

### 尺寸
- 外形：58mm x 43mm x 22mm
- 材质：ABS（白色/黑色）
- 安装：86 型底盒（可选）

### 开孔
- 状态指示灯孔：Φ3mm
- 配置按键孔：Φ4mm
- 接线端子孔：6mm x 15mm

## 生产测试

### 必测项目
1. 电源电压测试：3.3V ± 0.1V
2. WiFi 功能测试：连接成功率 > 95%
3. 继电器动作测试：吸合电压 < 4V
4. 状态 LED 测试：正常闪烁

### 测试工装
- USB 供电测试台
- 自动化测试脚本（通过串口）

## 认证要求

如需量产销售，建议进行以下认证：

1. **SRRC 认证**（中国无线电核准）
2. **CCC 认证**（中国强制性产品认证）
3. **RoHS 认证**（环保认证）

认证费用约：¥30,000-50,000
认证周期：约 2-3 个月
