### 采购建议

1. **小批量试产**：10-50 台
   - 直接在立创商城/嘉立创下单
   - PCB 选 5 天快板

2. **中批量生产**：100-1000 台
   - 联系供应商谈价格
   - 可考虑 ESP32 模组采购

3. **大批量生产**：1000+ 台
   - 找电子厂代工 SMT
   - 成本可降至 ¥15 以内

## 二、PCB 生产

### 设计文件

使用 KiCad 设计，导出 Gerber 文件。

### 生产规格

- 层数：2 层
- 板厚：1.6mm
- 铜厚：1oz
- 表面处理：HASL（有铅）或 ENIG（无铅）
- 最小线宽：6mil
- 最小孔径：0.3mm

### 下单步骤

1. 导出 Gerber 文件
2. 上传到嘉立创下单助手
3. 选择规格并下单
4. 生产周期：3-5 天

## 三、固件烧录

### 烧录工具

- USB-TTL 转换器（如 CH340）
- 或使用 ESP32 开发板

### 烧录步骤

1. **安装 PlatformIO**

```bash
pip install platformio
```

2. **编译固件**

```bash
cd firmware
pio run
```

3. **烧录固件**

```bash
pio run -t upload
```

### 批量烧录

使用多路烧录器（如 8 口 CH340），配合脚本：

```bash
#!/bin/bash
# batch_flash.sh
for port in /dev/ttyUSB*; do
    pio run -t upload --upload-port $port &
done
wait
```

## 四、功能测试

### 测试项目

| 序号 | 测试项 | 方法 | 判定标准 |
|------|--------|------|----------|
| 1 | 电源电压 | 万用表测量 3.3V | 3.25-3.35V |
| 2 | WiFi 连接 | 手机连接设备 AP | 可连接并可配网 |
| 3 | 继电器动作 | 控制开关 | 继电器吸合/释放正常 |
| 4 | 状态 LED | 观察 LED | 配网模式快闪，正常模式慢闪 |
| 5 | API 响应 | curl 测试 | 返回正确 JSON |

### 测试脚本

```python
import requests
import time

def test_device(ip):
    try:
        # 测试获取信息
        r = requests.get(f'http://{ip}/api/info', timeout=5)
        assert r.status_code == 200
        
        # 测试控制
        r = requests.post(f'http://{ip}/api/control', 
                         json={'state': True}, timeout=5)
        assert r.status_code == 200
        
        # 测试关闭
        r = requests.post(f'http://{ip}/api/control',
                         json={'state': False}, timeout=5)
        assert r.status_code == 200
        
        print(f'✅ {ip} 测试通过')
        return True
    except Exception as e:
        print(f'❌ {ip} 测试失败: {e}')
        return False

# 批量测试
for i in range(100, 110):
    test_device(f'192.168.1.{i}')
```

## 五、组装与包装
